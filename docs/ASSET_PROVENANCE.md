The first 3D model is constructed in code from general primitives and contains no imported mesh, reference photograph, texture pack, scan, or other third-party asset. Names and linked descriptions are used for factual identification.

The public site currently loads Three.js 0.180.0 from jsDelivr; Three.js is MIT licensed. The CSS references Google Fonts (DM Sans and DM Serif Display), served remotely under their respective open font licenses. Neither library nor font binaries are committed to this repository.

**Future specimen assets** must record author, source URL, actual license and permitted modifications, attribution text, date retrieved, coordinates, precision, coverage and hash. No asset may be used merely because it is publicly viewable.
