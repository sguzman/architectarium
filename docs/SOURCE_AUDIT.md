# Source acquisition checklist

## Parthenon
- [x] Official architecture overview (Parthenon Frieze / Acropolis Museum)
- [x] Official ionic-frieze documentation (Acropolis Museum)
- [x] Fundamental peristyle count (8 by 17) sourced
- [ ] Measured section, floor plan and column-axis datum
- [ ] Materials and finish stratigraphy
- [ ] Time-specific reconstruction state chosen and defended
- [ ] Spatial acceptance review for all semantic mesh bindings

## Pantheon
- [x] Official Italian government historical description
- [x] Rotunda diameter and oculus size recorded as claims
- [x] Initial architecture ontology inventory
- [ ] Independent measured survey or scholarly dimension cross-check
- [ ] Plan, elevation, longitudinal section and construction phases
- [ ] Inner and outer dome surface provenance
- [ ] Interior spatial path and floor drainage evidence
- [ ] Rights-cleared reconstruction assets and material images

Other queued specimens must complete the same sequence before modeling begins. An approved reference is not permission to reuse its photographs or survey diagrams.
